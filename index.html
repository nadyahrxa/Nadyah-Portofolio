FINAL-YEAR PROJECT JAN – JUL 2026

Network Intrusion Prevention System

I built a lab network where traffic passes through Snort 3 before reaching the target. The system uses machine learning to flag attacks and block their source IPs.

Implementation

  • Set up the inline network and connected AE-MLP detection to Snort 3, InfluxDB, and Grafana.
  • Ran five attack scenarios and checked blocking, throughput, jitter, packet loss, CPU usage, and memory usage.
